ASCII Face Comparison

Each block shows the same face (front, 80x40) rendered in a different mode. Compare them top-to-bottom — the variant closest to a real face is the winner.
1) color + RAMP_RICH (m3 default)
11-level ramp + 24-bit color — the Matrix-look with color shading.






2) color + RAMP_STD (10 levels)


Classic 10-level ramp + 24-bit color.
