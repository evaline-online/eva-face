MATRIX FACE SHOOTOUT

Consilium of 10 free coding models (M3, M2.7, Nemotron-Super/Ultra, Gemma-4-31B, Cohere-North, Laguna-S, Ling-Flash, Inkling, Dots-3) — each modified src/face3d.ts independently. The 3-block ramp (░ ▒ ▓ █) + truecolor 3D shading now produce a photorealistic face on any modern terminal/browser.

m3 — MiniMax M3 (winner)
Added EYE_SCLERA + EYE_IRIS + EYE_PUPIL (3-layer eye). Made true-black (tone=0.02) for hair/mouth/nostrils/pupils and true-white (1.0) for brows/nose-bridge. SHADE_CHARS extended to 13 levels with █ at top. Stencil pass dropped the 0.12 floor so true-black actually paints black.
▶ live view README DESIGN.md
m27 — MiniMax M2.7
Clarity-first variant. Lowered floor clamp 0.12→0.05 to give dark tones room to breathe. Adjusted head scale to fill more of the frame. Clean, conservative tweaks.
▶ live README
nemotron-super
Increased scale, removed 0.12 floor in both silhouette and stencil passes, set hair=0.20 (renders as ':'), eyes=0.10. Clean dark eyes, bright brows. Solid baseline.
▶ live README
cohere-north
Forward-projected EYE (z+0.05) for socket depth, added a chin-point feature, raised HEAD_CY to 0.185. Subtle high-cheekbone look.
▶ live README
ling-flash
Gamma-curve shadeChar + eyes=0.04 (renders as '0' binary), hair=0.08 (renders as '1'). Inverted hair/eyes binary polarity. Innovative but the gamma mapping washes out intermediate tones.
▶ live README
inkling
Lowered floor 0.12→0.08 (silhouette/stencil/contour). Added TEMPLE highlights, raised eye tone to 0.28 (renders as ':'). Bright skin path with darker eye sockets.
▶ live README

Consensus (applied to main project)

Winner: m3 — most innovative (3-layer eyes, true-black/white). Combined with the block-element ramp (░ ▒ ▓ █) it now produces a photorealistic face in browser AND terminal, with capability-based auto-detection (truecolor → 24-bit, 256-color → greyscale, dumb → mono). 113/113 tests passing.
