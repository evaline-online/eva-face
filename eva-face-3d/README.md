# Universal 3D Head — 5 Modes

Идентичная 3D голова в терминале и браузере: 3 скачанные открытые OBJ-модели голов,
разложенные на вершины и полигоны, рендерятся 5 способами с тенями, освещением и цветом.

## Запуск

**Браузер (веб-версия):**
```bash
python3 server.py          # → http://localhost:8101
```

**Терминал (ANSI 24-bit):**
```bash
python3 ascii_head.py      # выбор модели и режима, вращение, Ctrl+C — выход
```

## 5 режимов (одинаковы в обеих средах)

| # | Режим       | Что делает                                             |
|---|-------------|--------------------------------------------------------|
| 1 | WIREFRAME   | Рёбра полигонов + заполнение граней, цвет по глубине   |
| 2 | POINTS      | Облако вершин со свечением, размер по глубине          |
| 3 | MATRIX      | Падающая катакана, зелёное свечение, глубина-туман     |
| 4 | DEPTH       | Заливка граней с учётом глубины, «кожа» + атмосферная дымка |
| 5 | NORMAL      | Полноцветное освещение по нормалям + спекулярные блики |

## Модели (модель/объект, лицензии)

- `models/head_lightning.obj` — `head.obj` из Lightning-Chart (Blender head) — 6.7k verts
- `models/head_infinite.obj` — `bimba.obj` (human head, Pierre Alliez / common-3d-test-models) — 112k verts
- `models/head_spot.obj` — `spot.obj` (dog head, Keenan Crane / common-3d-test-models) — 4k verts

## Особенности

- Освещение: направленный свет + ambient + спекуляры (Blinn-Phong)
- Z-буфер для отсечения глубины
- Тени от фронтальных граней (back-face culling)
- Автоматическая децимация больших сеток для реального времени
- В браузере: drag — вращение, scroll — зум, авто-вращение
